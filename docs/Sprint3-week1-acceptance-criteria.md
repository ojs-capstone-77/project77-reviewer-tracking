## [CONFIGURATION] Requirements for configuring participation form and labels

**Owner:** BA
**Time:** 90 minutes

Acceptance criteria

Editors can configure which participation form fields are required or optional.

Editors can manage the list of contribution types available in the form.

Editors can manage the list of attendance options available in the form.

Editors can manage the list of shaping feedback options available in the form.

Editors can manage reviewer labels including experience level, methodology background, and expertise.

## [CONFIGURATION] Implement configurable participation form

**Owner:** DEV
**Time:** 240 minutes

Acceptance criteria

Editors can change which form fields are required or optional through journal settings.

Editors can add, edit, or remove contribution types.

Editors can add, edit, or remove attendance options.

Editors can add, edit, or remove shaping feedback options.

The Other field per reviewer and the general comments field are always present and cannot be removed.

Configuration changes apply to future forms and do not affect already submitted forms.

The form saves and loads correctly after configuration changes.

---

## [CONFIGURATION] Implement configurable labels

**Owner:** DEV
**Time:** 180 minutes

Acceptance criteria

Editors can manage the list of values for experience level, methodology background, and expertise.

Each label type supports the correct input behaviour, single choice or multiple choice.

Editors can assign label values to a reviewer.

Editors can see the full label history for a reviewer including who changed it and when.

Label changes save correctly and appear on the reviewer page and the dashboard.
