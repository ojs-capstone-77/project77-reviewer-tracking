# Configurable fields specifications **Participations Monitoring**

**Team:** 77
**Sprint:** 2

## 1. Our Project

The client requested that details should be configurable. This mean editord should be able to manage which fields appear in the participation recording form and whether those fields are required or optional.
This specifications defines what editors can configure. All configuration is managed by editors through journal settings. Review group leaders cannot add their own fields.

## 2. Configurable elements

Editors can configure the following elements:

### 2.1 Required vs optional fields

Editors can choose which fields review group leaders must fill out nd which are optional.

| Field | Ca be required | Can be optional |
|-------|----------------|-----------------|
| Attendance | Yes | Yes |
| Contribution types | Yes | Yes |
| Strengths demonstrated | Yes | Yes |
| Development opportunities | Yes | Yes |
| Shaping feedback response | Yes | Yes |
| COmments on contribution | Yes | Yes |
| Comments on shaping feedback | Yes | Yes |

### 2.2 Contribution types

Editors can ass, edit, or remove contibution type options. The default options are:

- Discussion
- Writing
- Analysis
- Editing
- Other

### 2.3 Attendance options

Editors can add, edit, or attendancxe options. The default options are:

- Attended
- Did not attend with apology
- Did not attend without apology
- N/A
- Other

### 2.4 Shaping feedback options

Editors can add, edit, or remove shaping feedback options. The default options are:

- Uploaded their notes or comments
- Commented on the feedback draft
- Differed creating the draft
- Created the draft

## 3.  Additional fields

These fields are always present and are not configurable. They are required by the client.

### 3.1 "Other" field per reviewer

A free text field per reviewer that allows the review group leader to add addtional comments not covered by the other fields.

### 3.2 General comments field

A free text field at the bottom of the form that allows the review group leader to communicate general ideas or suggestions to the editors. This field is not specific to any individual reviewer.

## 4. Who manages this

| Role | Can configure | Can record |
|------|---------------|------------|
| Managing editor | Yes | No |
| Quality review editor | Yes | No |
| Review group leader | No | Yes |

## 5. Assumptions

1. Editors manage configuration through journal settings.
2. Review group leaders cannot add their own fields.
3. The "Other" field and generak comments field are always available.
4. Default contribution types, attendance options, and shaping feedback options are pre populated.
5. Changes to configuration apply to future forms, not previously submitted ones.
